# Webly

Webly SV es un sitio web corporativo desarrollado como proyecto académico para la materia **Diseño de Páginas Web**.

El proyecto representa una idea de negocio hipotética enfocada en ofrecer servicios de desarrollo web para emprendedores, profesionales y pequeñas empresas de El Salvador.

Esta versión corresponde a una **segunda etapa del proyecto**, orientada a mejorar la estructura del código, la experiencia de usuario y el diseño visual del sitio original.

---

## Webly SV V2

La primera versión permitió construir la presencia digital inicial de Webly SV y posteriormente publicar el proyecto mediante Netlify.

Para esta segunda versión se realizará una renovación manteniendo la naturaleza estática e informativa del sitio, pero aplicando mejores prácticas de:

- UI/UX.
- Diseño responsive.
- Organización del código.
- Navegación.
- Jerarquía visual.
- Accesibilidad.
- Consistencia entre páginas.
- Optimización de recursos.

El objetivo es transformar el proyecto académico original en una implementación más moderna, organizada y cercana a un sitio corporativo real.

## Tecnologías

El sitio principal utiliza:

- HTML5.
- CSS3.
- JavaScript.
- Bootstrap 5.
- Font Awesome.
- Google Fonts.

El proyecto se mantiene deliberadamente como un sitio web estático, sin framework frontend ni backend, con el objetivo de reforzar los fundamentos de desarrollo y diseño web.

---

## Despliegue

La aplicación se encuentra desplegada utilizando Netlify, permitiendo publicar el sitio directamente desde archivos HTML, CSS y JavaScript.

Al ser un sitio estático no requiere instalación de dependencias ni servidor backend.

---

## Ejecución local

Clona el repositorio:

```bash
git clone https://github.com/alanantonioorellanaarguera-sudo/Webly_sv.git
```

Ingresa al proyecto:

```bash
cd Webly_sv
```

Luego abre:

```text
index.html
```

en cualquier navegador moderno.

También puede utilizarse una extensión como Live Server desde Visual Studio Code para trabajar durante el desarrollo.
